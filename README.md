# Full Stack Open

Ejercicios del curso [Full Stack Open](https://fullstackopen.com/es/) de la Universidad de Helsinki.

## Estructura

```
part0/            Fundamentos de las aplicaciones web (diagramas 0.4 - 0.6)
part1/
  courseinfo/     Ejercicios 1.1 - 1.5
  unicafe/        Ejercicios 1.6 - 1.11
  anecdotes/      Ejercicios 1.12 - 1.14
```

Cada parte tiene su propio directorio, con un subdirectorio para cada conjunto de ejercicios.

## Partes

- [Parte 0: Fundamentos de las aplicaciones web](./part0)
- [Parte 1: Introducción a React](./part1)

## Ejecutar un proyecto

Cada proyecto de React se creó con Vite:

```bash
cd part1/courseinfo
npm install
npm run dev
```
