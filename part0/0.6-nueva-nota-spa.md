# 0.6 - Nueva nota en la SPA

Qué pasa cuando creo una nota en la versión SPA.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: escribo la nota y aprieto Save

    Note right of browser: el JS frena el submit del form con e.preventDefault(), agrega la nota a la lista y la vuelve a dibujar

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note left of server: la nota llega como JSON con content y date
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: no se recarga la pagina
```

Acá la página no se recarga: se hace un solo POST con la nota en JSON y el server contesta 201. La nota ya se ve antes de que responda porque el JS la agrega directamente.
